# cwiczenia_git

Repozytorium do ćwiczeń z systemu kontroli wersji **Git**.

## Struktura repozytorium

```
cwiczenia_git/
└── README.md   # ten plik – opis repozytorium i jego struktury
```

Na ten moment repozytorium zawiera wyłącznie plik `README.md`. Historia
składa się z jednego commita (`Initial commit`, 2016), a główną gałęzią
jest `master`.

## Jak zacząć

```bash
git clone https://github.com/skretu/cwiczenia_git.git
cd cwiczenia_git
```

## Przykładowe ćwiczenia

- tworzenie commitów (`git add`, `git commit`) i przeglądanie historii (`git log`),
- praca na gałęziach (`git branch`, `git switch`, `git merge`),
- rozwiązywanie konfliktów przy scalaniu,
- synchronizacja ze zdalnym repozytorium (`git fetch`, `git pull`, `git push`).
